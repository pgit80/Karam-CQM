1. Clone the repo 
2. Navigate to the project directory
3. Go to Frontapp-> Run `npm i` to install dependencies for frontend project -> after instllation run `npm start`
4. Go to Backapp-> Run `npm i` to install dependencies for backend of project -> after installation run `node index.js`
5. Make sure npm is installed and configured properly
